# ai-healthcare-chatbot
AI Healthcare Chatbot with multilingual support using Streamlit, LangChain, and ChromaDB
# 🏥 Rural Health Info Bot

## Project Description
This project is a multilingual healthcare chatbot developed using Python and Streamlit.

The chatbot helps rural users get healthcare information in multiple languages.

## Features
- Healthcare FAQ chatbot
- Multilingual support
- Appointment guidance
- Hospital department guidance
- Citations
- Admin panel

## Technologies Used
- Python
- Streamlit
- Deep Translator
- FuzzyWuzzy

## Run Project
```bash
streamlit run frontend/app.py
```
